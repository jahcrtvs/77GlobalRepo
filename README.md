# CDP Maven and Git Demo

This repository is used for the CDP training program at **Seven Seven Global Services**.

The main purpose of this repository is to practice and demonstrate the use of **Git** and **Maven** together in a Java project.

## Purpose

This project is used for training and demo activities, including:

- Creating and managing a Maven project
- Managing project files using Git
- Creating commits and tracking changes
- Working with branches
- Using Maven to build and manage the project
- Practicing basic Git workflows
